# shoaibnew

Food ordering system (SnackNova project)

This repository contains a React + Vite frontend and an Express/MongoDB backend for a food ordering application.

Notes:
- Backend: `server/index.js` implements JWT authentication and uses `bcryptjs` + `jsonwebtoken`.
- Frontend: built with Vite and React; see `src/components` for auth pages.

Feel free to update this README with installation and deployment instructions.
